# Facturación electrónica ARCA desde Node.js

`facturas` es un SDK TypeScript para emitir facturas, notas de crédito y notas de débito, consultar el Padrón y trabajar directamente con WSFE y WSMTXCA.

<Note>
  El paquete es solo ESM y requiere Node.js 20 o posterior. Se conecta directo a ARCA, sin proxy ni servicio alojado.
</Note>

## Ejemplo mínimo

```typescript
import { createArcaClient } from "facturas";

const arca = createArcaClient();

const resultado = await arca.issue({
  issuer: "monotributo",
  salesPoint: 3,
  to: { condition: "consumidor_final" },
  items: [{ amount: 150_000 }], // ARS 1.500,00 en centavos
});

if (resultado.kind === "authorized") {
  console.log(resultado.voucher.cae, resultado.voucher.number);
}
```

El cliente descubre `ARCA_TAX_ID`, `ARCA_CERTIFICATE_PEM`,
`ARCA_PRIVATE_KEY_PEM` y `ARCA_ENVIRONMENT` desde el entorno. Antes de pasar a
producción, seguí el [inicio rápido](/getting-started/quickstart) completo y
tratá los cuatro resultados fiscales posibles.

## Contrato de resultados

| Resultado | Qué significa | Qué tenés que hacer |
| --- | --- | --- |
| `authorized` | ARCA autorizó el comprobante. | Guardá el número, el CAE y su vencimiento. |
| `rejected` | ARCA rechazó el pedido de forma definitiva. | Revisá `issues`. No cambies el input ligado a la clave. |
| `indeterminate` | No se puede demostrar todavía si ARCA lo autorizó. | Conservá la evidencia y conciliá antes de reintentar. |
| `conflict` | El número reservado pertenece a otro comprobante. | Detené el flujo e investigá. |

<Warning>
  A diferencia de Stripe, ARCA no recibe una clave de idempotencia para reconocer un reintento. `facturas` te permite asociar una clave de tu aplicación a un store compartido. Así puede recuperar el número reservado y evitar una segunda emisión.
</Warning>

## Empezá con `issue()`

`issue()` es el camino normal para emitir. Recibe datos de tu negocio y arma la
factura, el IVA y el pedido que espera ARCA. La guía de
[Facturas](/guides/invoices) documenta todos sus campos y resultados.

Los métodos de `client.wsfe`, `client.wsmtxca` y `client.padron` siguen
disponibles para consultas y operaciones que `issue()` no cubre. Usalos cuando
necesites controlar un número ya reservado o enviar un campo propio del
protocolo. Están en [Métodos directos de ARCA](/reference/arca-services).
