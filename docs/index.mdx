# Facturación electrónica ARCA desde Node.js

`facturas` es un SDK TypeScript para emitir facturas, notas de crédito y notas de débito, consultar el Padrón y trabajar directamente con WSFE y WSMTXCA.

<Note>
  El paquete es solo ESM, requiere Node.js 20 o posterior y se conecta directo a ARCA: no usa un proxy ni un servicio alojado.
</Note>

## Ejemplo mínimo

```typescript
import { createArcaClient } from "facturas";

const arca = createArcaClient();

const resultado = await arca.issue({
  issuer: "monotributo",
  salesPoint: 3,
  to: { condition: "consumidor_final" },
  items: [{ amount: 150_000 }], // ARS 1.500,00 en centavos
});

if (resultado.kind === "authorized") {
  console.log(resultado.cae, resultado.voucherNumber);
}
```

El cliente descubre `ARCA_TAX_ID`, `ARCA_CERTIFICATE` y `ARCA_PRIVATE_KEY` desde el entorno. Antes de producción, seguí el [inicio rápido](/getting-started/quickstart) completo y tratá los cuatro resultados fiscales posibles.

## Contrato de resultados

| Resultado | Qué significa | Qué tenés que hacer |
| --- | --- | --- |
| `authorized` | ARCA autorizó el comprobante. | Guardá el número, el CAE y su vencimiento. |
| `rejected` | ARCA rechazó el pedido de forma definitiva. | Revisá `issues`; no cambies el input ligado a la clave. |
| `indeterminate` | No se puede demostrar todavía si ARCA lo autorizó. | Conservá la evidencia y conciliá antes de reintentar. |
| `conflict` | El número reservado pertenece a otro comprobante. | Detené el flujo e investigá. |

<Warning>
  Sin `idempotencyKey` y un store durable, repetir una emisión después de una caída puede generar un segundo comprobante real.
</Warning>
